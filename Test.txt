Originally, longer queries and queries with stopwords performed poorly with respect to time.
In order to optimize the engine for longer queries (8 or more words),
we only calculated the cosine similarity scores for documents that 
contain all of the query terms.

Also, most if not all search results had poor relevance to the query.
In order to solve the relevance issue, we implemented a tf-idf/cosine similarity
ranking scheme, which improved the relevance of result documents.
