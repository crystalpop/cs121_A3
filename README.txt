Running the indexer:

To run the indexer, simply type "python indexer.py" into the terminal.
The program will create a directory called index_files,
where the partial indexes will be offloaded to. 
After the partial indexes have been merged, they will be deleted
and the final index called "final_inverted_index.json" will be written to
the index_files folder.



Running the search engine from the terminal:

To start up the search interface, type "python A3part2.py" into the terminal.
A message denoting the boot time of the engine will appear, and there will
be a prompt for a query.


Performing a query:

After starting the search engine from the terminal, 
simply type your query at the prompt "Enter a query: "
and press Enter or Return to view the top 5 results.
